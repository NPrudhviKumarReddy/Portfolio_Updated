# Portfolio deployment checklist

Upload `index.html`, `style.css`, `CNAME`, `robots.txt` and `sitemap.xml` to the website root.

Do not upload the supplied `resume.pdf` publicly: it contains a personal phone number and direct email address. Use a separately redacted public resume or provide it privately to verified recruiters.

After deployment:

1. Test the live URL and mobile layout.
2. Validate the JSON-LD with Google's Rich Results Test.
3. Submit `sitemap.xml` in Google Search Console.
4. Inspect the home page and request indexing.
5. Keep the verified Instagram URL `https://www.instagram.com/reddy_prudhvi_/` consistent with the website and other professional profiles.
6. Add GitHub, ORCID, Google Scholar and ResearchGate only when each profile is complete and verified.
7. Use a dedicated public contact alias if email contact is required; do not republish a primary personal email or phone number.

Search rankings cannot be guaranteed. These files improve technical eligibility, entity consistency and privacy while avoiding deceptive SEO practices.
